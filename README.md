# xuMax interActive website

Source for **https://www.xumax.site**: the MaxBot homepage plus SEO landing pages for services and countries.

## What's where

| Path | What it is |
|---|---|
| `index.html` | The homepage (a Design Component: `<x-dc>` template + logic class). Edit this one. |
| `archive/index-v1.html` | The previous homepage, kept for reference. Not deployed. |
| `support.js`, `vendor/` | Runtime that renders the homepage. Don't edit. |
| `assets/` | Uploaded media. |
| `seo/` | SEO source: `config.js` (business details), `content.js` (all landing-page text), `build.js` (generator), `SEO-STRATEGY.md`. |
| `site/` | **The built website. Upload the contents of this folder.** Generated by `node seo/build.js`; don't edit by hand. |

## Build

```bash
node seo/build.js
```

Rebuilds `site/` from `index.html` and `seo/`.

## Automatic publishing

Changes made through Claude Code in this folder are rebuilt, committed and pushed to `main` automatically at the end of each turn (see `.claude/settings.json` and `scripts/autopush.sh`). A log of each run is kept in `.claude/autopush.log` (not committed).

### One-time GitHub sign-in on this Mac

GitHub CLI is installed at `~/.local/bin/gh`. Sign in through the browser (works with a Google login, no password needed):

```bash
~/.local/bin/gh auth login --hostname github.com --git-protocol https --web
~/.local/bin/gh auth setup-git
```

Answer **Y** to “Authenticate Git with your GitHub credentials?”, press Enter to open the browser, and enter the one-time code it shows. After that every push, including the automatic ones, works without asking.
