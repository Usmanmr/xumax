# xuMax website

- This folder IS the website (upload/deploy its contents to public_html). Tooling lives in hidden `.build/`, which `.htaccess` keeps away from visitors.
- `index.html` is the homepage, a Design Component: markup inside `<x-dc>`, styles in `<helmet><style>`, logic in the single `data-dc-script` class; close every element, holes are dotted lookups only, never build UI from script. Don't edit `support.js` or `vendor/`.
- The block between `<!-- seo:start -->` and `<!-- seo:end -->` in `index.html` and the folders `services/`, `where-we-work/`, `pakistan/`, `uae/`, `saudi-arabia/`, `qatar/`, `kuwait/`, `bahrain/`, `oman/`, `usa/`, plus `sitemap.xml`, `robots.txt`, `llms.txt` are generated by `node .build/seo/build.js` from `.build/seo/config.js` and `content.js`; edit those, not the output. Landing-page styles: `css/seo.css`.
- `contact.php` emails Problem Hunt form submissions to usmanmr@gmail.com.
- Publishing is automatic: the Stop hook (`.build/autopush.sh`) regenerates pages, commits leftovers and pushes `main` to https://github.com/Usmanmr/xumax at the end of every turn. The owner wants every change pushed.
- Before ending a turn that changed files, commit them yourself with a descriptive message (ending with the Co-Authored-By trailer) so the history reads well; the hook then only pushes.
- The owner does the cPanel deployment; `.build/cpanel-deploy.sh` and `.cpanel.yml` are ready for it.
