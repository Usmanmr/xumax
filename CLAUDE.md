# xuMax website

- Edit `index-v2.html` (homepage) and `seo/` (landing pages). Never edit `index.html` (old version), `support.js` or `vendor/`.
- `index-v2.html` is a Design Component: markup inside `<x-dc>`, styles in `<helmet><style>`, logic in the single `data-dc-script` class; close every element, holes are dotted lookups only, never build UI from script.
- `site/` is generated by `node seo/build.js`; don't edit it by hand.
- Publishing is automatic: the Stop hook (`scripts/autopush.sh`) rebuilds `site/`, commits leftovers and pushes `main` to https://github.com/Usmanmr/xumax at the end of every turn. The owner wants every change pushed.
- Before ending a turn that changed files, commit them yourself with a descriptive message (ending with the Co-Authored-By trailer) so the history reads well; the hook then only pushes.
